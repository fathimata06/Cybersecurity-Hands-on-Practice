
# Week 2 - Day 5: Windows Administration and Security Monitoring

## Objective
To understand Windows system administration, monitor running processes and network connections, explore Windows services, and investigate security events using PowerShell and Event Viewer.

## Topics Covered

### 1. Process Management
- Listed running processes.
- Examined process details.
- Used PowerShell to monitor processes.
- Understood Process IDs (PID).

### 2. Windows Services
- Explored Windows services.
- Used Get-Service to list services.
- Understood service status and startup behaviour.

### 3. Network Connection Monitoring
- Used Get-NetTCPConnection.
- Examined local and remote IP addresses.
- Identified local and remote ports.
- Explored TCP connection states.

### 4. Windows Event Logs
- Explored Windows Event Viewer.
- Investigated security-related events.
- Checked for failed login attempts.
- Documented that no failed login events were found during the investigation.

### 5. Hands-on Learning
- Practiced Windows administration using PowerShell.
- Completed TryHackMe Windows Fundamentals Parts 2 and 3.

## Tools Used
- Windows Virtual Machine
- PowerShell
- Windows Event Viewer
- TryHackMe

## Outcome
Gained practical experience with Windows process monitoring, service management, TCP connection analysis and basic security event investigation.
