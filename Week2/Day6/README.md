
# Week 2 - Day 6: Docker Fundamentals and Container Deployment

## Objective
To understand Docker fundamentals, run containers, and deploy a multi-container application using Docker Compose.

## Topics Covered

### 1. Docker Fundamentals
- Understanding Docker and containers.
- Understanding Docker images and containers.
- Learning how Docker simplifies application deployment.
- Running containers using Docker commands.

### 2. Running Docker Containers
- Executed the Docker Hello World container.
- Used `docker run hello-world`.
- Observed how Docker downloads images from Docker Hub.
- Understood the container execution process.

### 3. Docker Compose
- Learned the purpose of Docker Compose.
- Used a Docker Compose YAML configuration file.
- Created and managed a multi-container application.
- Started multiple services using Docker Compose.

### 4. WordPress and MariaDB Deployment
- Deployed WordPress using Docker Compose.
- Configured MariaDB as the database service.
- Connected WordPress with the MariaDB database.
- Started and managed both containers.
- Checked running containers using `docker compose ps`.

### 5. Host Machine Access and Port Mapping
- Configured port mapping to access the WordPress application from the host machine.
- Accessed the application through the host machine's web browser.
- Verified that WordPress was running successfully.

## Tools and Technologies Used
- Kali Linux
- Docker
- Docker Compose
- Docker Hub
- WordPress
- MariaDB


## Outcome
Gained practical experience with Docker fundamentals, container execution, Docker Compose and multi-container application deployment.

Successfully deployed a WordPress application with MariaDB and accessed it through the host machine's browser.
