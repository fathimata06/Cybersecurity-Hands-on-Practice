
# Week 2 - Day 2: Linux Filesystem, Special Permissions and ACL

## Topics Covered

1. Linux Filesystem Hierarchy (FHS)
2. SUID (Set User ID)
3. SGID (Set Group ID)
4. Sticky Bit
5. Hard Links
6. Symbolic Links (Soft Links)
7. Access Control Lists (ACL)

## Objective

To understand Linux filesystem structure, practice special file permissions, explore hard and symbolic links, and configure user-specific permissions using ACL in Kali Linux.

## Practical Skills

- Linux filesystem exploration
- File permission management
- Identifying permission-related security risks
- Creating and examining links
- Configuring and testing ACL permissions
