
# Week 2 - Day 4: Windows Fundamentals and System Administration

## Objective
To set up a Windows virtual machine and understand basic Windows administration and system configuration.

## Topics Covered

### 1. Windows Virtual Machine Setup
- Installed Windows in VirtualBox.
- Configured the virtual machine.
- Installed VirtualBox Guest Additions.

### 2. Windows Fundamentals
- Explored the Windows operating system.
- Completed TryHackMe Windows Fundamentals Part 1.
- Explored basic Windows features and administration.

### 3. Windows Registry
- Explored the Windows Registry using Registry Editor (regedit).
- Understood the purpose of registry keys and values.
- Learned about the importance of the Registry in system configuration.

### 4. Linux vs Windows
- Compared basic administration features.
- Explored differences in system configuration and security-related locations.

## Tools Used
- Oracle VirtualBox
- Windows Virtual Machine
- VirtualBox Guest Additions
- TryHackMe

## Outcome
Gained practical exposure to Windows virtual machine setup, Windows fundamentals, Registry Editor and basic system administration.
