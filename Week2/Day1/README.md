
# Week 2 - Day 1: Linux Boot Process and System Administration

## Objective
To understand the Linux boot process and learn how the system starts from power-on to the login prompt.

## Topics Covered

1. BIOS/UEFI and POST
2. GRUB Bootloader
3. Linux Kernel Loading
4. Initramfs
5. systemd (PID 1)
6. Systemd Target Units
7. Linux Boot Sequence

## Practical Work
- Explored the Linux boot process.
- Investigated systemd and its role in system startup.
- Checked system targets and services.
- Used Linux commands to examine boot-related information.
- Practiced identifying different stages of the boot process.

## Tools Used
- Kali Linux
- Linux Terminal

## Outcome
Gained practical knowledge of the Linux boot sequence, system initialization, systemd and service management.
