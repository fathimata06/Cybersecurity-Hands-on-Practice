
# Week 2 - Day 3: Linux Package Management, Process Management, Systemd Services and Cron Jobs

## Objective
To understand Linux package management, monitor running processes, create and manage systemd services, and automate tasks using cron jobs.

## Topics Covered

### 1. Linux Package Management
- apt update and upgrade
- apt-cache policy
- dpkg -L and dpkg -S
- apt-mark hold and unhold
- Removing vs purging packages

### 2. Process Management
- Listing running processes
- Checking process IDs (PID)
- Using ps and pgrep
- Understanding process details

### 3. Systemd Services
- Understanding systemd
- Creating a custom systemd service
- Managing and checking services
- Understanding service status

### 4. Cron Jobs
- Understanding scheduled tasks
- Creating cron jobs
- Editing crontab
- Verifying scheduled tasks

## Tools Used
- Kali Linux
- Linux Terminal
- APT and DPKG
- systemd
- Cron

## Outcome
Gained practical knowledge of Linux package management, process monitoring, service management and task scheduling.
