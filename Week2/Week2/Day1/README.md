
# Week 2 - Day 1: Linux Boot Process and System Administration

## Topics Covered

- BIOS/UEFI and POST
- GRUB Bootloader
- Linux Kernel Loading
- Initramfs
- systemd (PID 1)
- Systemd Target Units
- Linux Boot Sequence
- Practical investigation using Kali Linux

## Objective

To understand and trace the complete Linux boot process, from system startup to the login prompt, using hands-on commands in Kali Linux.
